# 🎭 CueSide (큐사이드)
연극·영화 배우를 위한 AI 상대역 및 대본 분석 파트너 (Design Spec v2.0 MVP)

## 실행 방법 (Streamlit Cloud)
1. 이 저장소의 파일(`app.py`, `requirements.txt`, `samples/`)을 본인의 GitHub Repository에 업로드합니다.
2. [Streamlit Cloud](https://share.streamlit.io/)에 GitHub 계정으로 로그인 후 `New app`을 클릭합니다.
3. 업로드한 Repository와 `app.py`를 선택하고 `Deploy`를 누르면 즉시 무료 웹 앱으로 배포됩니다.
